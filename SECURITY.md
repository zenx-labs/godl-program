# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. **Do not open a public issue.**

1. **Submit a report via [GitHub Security Advisories](../../security/advisories/new)** (Security tab → Report a vulnerability).
2. If you do not get a response within **8 hours**, reach out directly:
   - Email: bootapollo@pm.me
   - Telegram: [@bootapollo](https://t.me/bootapollo)

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Any relevant logs, transactions, or proof-of-concept

We will acknowledge your report as soon as possible and keep you updated on the fix.

## Disclosure

Please give us a reasonable amount of time to address the issue before any public disclosure.
